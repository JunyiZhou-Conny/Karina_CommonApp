## What to filter (one domain at a time)

Do this four times.

1. Click **Find Questions**.
2. Set:
   - **Assessment:** SAT (skip PSAT unless you want easier cousins)
   - **Test:** Math
   - **Difficulty:** Hard only
   - **Domain:** exactly one of
     - Algebra
     - Advanced Math
     - Problem-Solving and Data Analysis
     - Geometry and Trigonometry
3. Turn **on** “Exclude active questions” if you see it. That keeps current Bluebook items unused — same idea as saving Tests 1–11.
4. Select up to **20** items. Click **Export**.
5. Export **twice** for the same selection:
   - **No answers** → print for Karina
   - **With correct answers and explanations** → keep for you
6. If that domain still has more Hard items, clear the selection and export the next 20. Repeat until the domain is done. Then change the domain and start again.

Suggested file names when you save:

```
QB-SAT-Hard-Algebra-01-questions.pdf
QB-SAT-Hard-Algebra-01-answers.pdf
QB-SAT-Hard-AdvancedMath-01-questions.pdf
QB-SAT-Hard-AdvancedMath-01-answers.pdf
QB-SAT-Hard-PSDA-01-questions.pdf
QB-SAT-Hard-PSDA-01-answers.pdf
QB-SAT-Hard-Geometry-01-questions.pdf
QB-SAT-Hard-Geometry-01-answers.pdf
```
