**S1.** \(\dfrac{(x-3)(x+3)}{x-3}=x+3\). **B**.

**S2.** \(\dfrac{2x(x^2-4)}{2x}=x^2-4\).

**S3.** Difference of cubes \(a=2x\), \(b=3\): \((2x-3)(4x^2+6x+9)\).

**S4.** \((x-3)(4x-2)=2(x-3)(2x-1)\). **A**.  
(C is \(4x^2-10x+6\), not the expansion \(4x^2-14x+6\).)

**S5.** \((3x^2 y)^2=9x^4 y^2\) → \(a+b+c=9+4+2=15\).

**S6.** \(\sqrt{18x^2}=x\sqrt{18}=3x\sqrt{2}\) for \(x>0\).

**S7.** \(3x+1=10\) → \(x=3\); \(3x+1=-10\) → \(x=-\dfrac{11}{3}\).

**S8.** \(-3<x-4<3\) → \(1<x<7\).

**S9.** \(2x-5=x+1\) → \(x=6\); \(2x-5=-(x+1)\) → \(2x-5=-x-1\) → \(3x=4\) → \(x=\dfrac{4}{3}\).

**S10.** Absolute value cannot equal a negative. **A** (0 solutions).

**S11.** \(2x-3=\pm 7\) → \(x=5\) or \(x=-2\). Larger **5**.

**S12.** \(x+3=2(x-1)=2x-2\) → \(5=x\). Not 1, so valid.

**S13.** Multiply by \(x-2\): \(1+3(x-2)=5\) → \(1+3x-6=5\) → \(3x=10\) → \(x=\dfrac{10}{3}\).

**S14.** \(\dfrac{x-2}{x-1}=1\) → \(x-2=x-1\) → \(-2=-1\), contradiction. \(x=1\) forbidden. **No solution**.

**S15.** Undefined at \(x=2\). Numerator \((x-2)(x-3)\) → simplified \(x-3\).

**S16.** \(\dfrac{4}{x}=3-\dfrac12=\dfrac52\) → \(x=\dfrac{8}{5}\).

**S17.** \(2x+3=x^2\) → \(x^2-2x-3=0\) → \(x=3\) or \(-1\).  
\(x=-1\): \(\sqrt{1}=1\neq -1\). **Only \(x=3\)**.

**S18.** \(x+12=x^2\) → \(x^2-x-12=0\) → \(x=4\) or \(-3\). Only **\(x=4\)**.

**S19.** \(3x-2=16\) → \(x=6\). Check: \(\sqrt{16}=4\). ✓

**S20.** \(5x+1=(x+1)^2=x^2+2x+1\) → \(x^2-3x=0\) → \(x=0\) or \(3\). Both check. Larger **3**.

**E1.** \(x+4\).  
**E2.** \(x=4\) or \(x=-14\).  
**E3.** **No.** \(\sqrt{1}=1\) but \(1-2=-1\). Also \(\sqrt{\cdot}\) cannot equal a negative.
