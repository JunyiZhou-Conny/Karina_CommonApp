# SAT Math Resources (Official-First)

## College Board (primary)

| Resource | URL | Use |
|---|---|---|
| Math section overview | https://satsuite.collegeboard.org/sat/whats-on-the-test/math/overview | Domains + question counts |
| Digital SAT specs overview (PDF) | https://satsuite.collegeboard.org/media/pdf/digital-sat-test-spec-overview.pdf | Timing, adaptive design |
| Bluebook practice tests | https://satsuite.collegeboard.org/practice/practice-tests/bluebook | Full-length timed practice |
| SAT Suite Question Bank | https://satsuitequestionbank.collegeboard.org/ | Official items; filter Math → **Hard**. This is the robust source for extra hard items without spending Tests 1–11. |
| Student Question Bank (skill list) | https://satsuite.collegeboard.org/practice/student-question-bank/math | What each Math skill looks like |
| Digital SAT sample questions | https://satsuite.collegeboard.org/media/pdf/digital-sat-sample-questions.pdf | Public worked samples (not a Module 2 #24–#27 set) |

## How we use these in this repo

- Lesson examples in `weekend-*/` are **instructor-created SAT-style** items unless marked otherwise.
- For authentic College Board items: pull from Question Bank / Bluebook, then log misses against skill IDs in [`01-math-content-map.md`](01-math-content-map.md).
- Official paper practice PDFs already in this repo: [`official/`](official/). Reserve Tests **1–11** for later timed sits.
- Do **not** paste full copyrighted Bluebook on-screen forms into this repo.

## Hard Module 2 #24–#27 — what actually exists

There is **no robust public archive** of “actual administered SAT, Module 2 questions 24–27, every past exam.”

| Source | Robust? | Why |
|---|---|---|
| Official paper practice Tests 1–11, Math Module 2 #24–#27 | Yes, official | Already in this repo. **Do not spend these yet.** Paper tests have 27 questions; Bluebook test day has **22**. |
| SAT Suite Question Bank, Math, difficulty **Hard** | Yes, official | Best extra supply. Not labeled “#24–#27,” but these are the same skill/difficulty band. |
| College Board sample-questions PDF | Yes, official | Small mixed set. Not a last-four Module 2 pack. |
| Khan Academy Official SAT practice | Yes, official partner | Adaptive practice; not a downloadable 24–27 list. |
| Third-party “hard Module 2” PDFs / “real SAT leak” sites | **No** | Not College Board. Many are unofficial clones or unauthorized copies. Do not treat them as actual exams. |

If you later upload other official files, we can add a last-four folder. Until then, extra hard items in this repo are **instructor-written** (see Targeted Set 01 items 21–25).
